## Production checklist
- HTTPS only
- Secure authentication/session handling
- Secrets kept server-side
- Resume/JD file validation and malware scanning strategy
- Rate limiting
- Audit/error logging
- Database backups
- Data deletion workflow
- Privacy policy and data-use disclosures
- Accessibility testing
- Mobile/desktop responsive testing
- Browser compatibility testing
- Automated tests and CI
- Dependency/security scanning
- Production monitoring

## Deployment
The finalized application can be deployed from the GitHub repository after the backend and secure environment variables are configured.
