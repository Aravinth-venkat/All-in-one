# V2 — Website Functionality

## Core modules
- Resume upload: PDF, DOC, DOCX, TXT
- Resume text extraction and structured profile
- IT / Non-IT classification with user confirmation
- Fresher / experienced profile
- Skill, role, experience and project extraction
- Job Description upload/paste
- JD requirement extraction
- Resume ↔ JD comparison
- Skill gap and personalized preparation plan
- Learning lessons, quizzes, free-text answers and scenarios
- Code Lab: Java, Python, JavaScript, C#, C/C++, SQL, TypeScript
- ServiceNow Script Lab
- Debugging challenges
- Interview question bank
- Mock interview state and progress
- Voice input UI
- XP, streaks, levels, skill mastery

## Design rule
Prototype behavior must remain usable without an external AI provider. AI features should have graceful fallback states.
